# 🛒 Shopping Cart
A React-based shopping cart application that allows users to browse products, add items to their cart, and manage quantities. Built with React Router for navigation and API integration for product fetching.

## 📌 Introduction

This project is a React-based Shopping Cart application built as part of an e-commerce. It demonstrates key concepts such as React Router, state management and API integration.

## 🚀 Features

- 🏠 Home Page: Displays basic information about the store.
- 🛍️ Shop Page: Lists products fetched from the FakeStore API.
- ➕ Add to Cart: Users can add items to their cart, adjust quantities, and view totals.
- 🔄 Cart Management: Implements increment/decrement buttons and manual input for quantity selection.
- 🎨 Styling: Styled for a clean and responsive UI.
- 🌐 Routing: Implemented with React Router for seamless navigation.

## 🛠️ Technologies Used

- React.js (with hooks)
- React Router for navigation
- FakeStore API for fetching products
- CSS

## 🔧 Setup & Installation
1. Clone the repository:
```bash
git clone https://github.com/jacob-guerrero/odin-shopping-cart.git
cd odin-shopping-cart
```
2. Install dependencies:
```bash
npm install
```
3. Start the development server:
```bash
npm run dev
```

## 🚀 Deployment
Deployed using Netlify. Live Demo [here](https://shopping-cart-jg.netlify.app)
